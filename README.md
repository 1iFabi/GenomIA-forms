# Genomia Forms

React and Vite application for GenomIA. Pages live in `src/pages/`, sections in `src/components/<section>/` with their styles colocated, and shared UI in `src/components/ui/`.

## Development

Install dependencies and start the Vite development server:

```sh
npm install
npm run dev
```

## Typecheck and production build

```sh
npm run typecheck
npm run build
```

## Preview the production build

```sh
npm run preview
```

The hero loads Plus Jakarta Sans, its video, and poster from external URLs, so these assets require an internet connection.
