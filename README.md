# Genomia Forms

React and Vite application for the Sellix hero design. The page implementation is in `src/pages/HomePage.tsx` with its styles colocated in `src/pages/HomePage.css`.

## Development

Install dependencies and start the Vite development server:

```sh
npm install
npm run dev
```

## Typecheck and production build

```sh
npm run typecheck
npm run build
```

## Preview the production build

```sh
npm run preview
```

The hero loads Plus Jakarta Sans, its video, and poster from external URLs, so these assets require an internet connection.
